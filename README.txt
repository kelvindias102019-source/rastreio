RASTREIO BRASIL — PORTAL DE ACOMPANHAMENTO

Arquivos:
- index.html
- styles.css
- script.js

Recursos:
- Layout responsivo para celular, tablet e desktop.
- Campo de código de rastreamento.
- Consulta de CEP integrada ao ViaCEP.
- Confirmação de número e complemento.
- Endereço salvo no navegador.
- Linha do tempo interativa.
- Botões de salvar, copiar e compartilhar.

Observação:
Este projeto usa marca própria e funciona como serviço independente de acompanhamento, sem vínculo com os Correios ou qualquer transportadora.
